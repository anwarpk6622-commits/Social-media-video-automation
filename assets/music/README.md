# Background Music (Phase 4)

Sirf woh music rakhein jis ka **license** aap ke paas ho (warna YouTube copyright claim aa sakta hai).
Free aur mehfooz zariye:
- YouTube Studio → **Audio Library** (free, YouTube ke liye)
- Pixabay Music (free, attribution zaroori nahi)
- Har file ke saath us ka license / source note kar lein (jaise `song-name.txt`).
